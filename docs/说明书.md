# Living Steward 1.0 便携版 · 说明书

> **仓库内说明**：本文件原为便携包使用手册。本仓库收录的是**应用源码**，对应便携包中的 `resources/app/` 目录 —— 仓库根目录的 `main.cjs`、`core/`、`gui/`、`plugins/` 即其内容。模型权重、Electron 运行时与 API 密钥均不在仓库内，需自行准备。

生活主管（Living Steward）= 本机电脑管家。云端监督脑只负责拆目标、派任务、收状态位；
本地执行脑带着插件手脚在你机器上干活；**任何本地细节不出本机**。
内核只有 3 个文件（core/kernel.mjs、core/loop.mjs、core/llm.mjs），其余一切皆插件（everything is a plugin）。
1.0 = 第一个完整可用版（Codex 功能复刻内核）。

## 一、目录结构

```
LivingSteward-1.0-portable/
├─ 启动 Living Steward.cmd   ← 双击这个
├─ Living Steward.exe        ← Electron 主程序（运行时已内置，无需安装 Node/Electron）
├─ brains/                   ← 本地双脑：llama-server(Vulkan 通用版) + 模型权重 + brains.json
│   ├─ Qwen3-8B-Q4_K_M.gguf      质量脑 :8080（约 5GB 内存/显存）
│   ├─ Qwen3.5-2B-Q4_K_M.gguf    速度脑 :8081（compaction/快答）
│   └─ brains.json               脑配置（端口/模型/参数）
├─ deepseek.key              ← 云脑 DeepSeek API 密钥（⚠ 私密，见第六节）
├─ workspace/                ← 默认工作区（本地脑写文件只允许在工作区内）
├─ userdata/                 ← 浏览器缓存/本地存储（随包携带，可删，删后自动重建）
├─ resources/app/            ← 应用源码：main.cjs + core/ + gui/ + plugins/（9 个插件）
│   └─ data/                 ← 会话记录/配置/审计（随包携带，分享前可删）
└─ 说明书.md
```

## 二、快速开始（本机或任何新机器）

1. 整个文件夹拷到目标机任意目录（或解压 zip），**无需安装任何东西**。
2. 双击 `启动 Living Steward.cmd`（内含 `--no-sandbox` 兼容参数，见第七节 EDR 条目；
   干净机器上直接双击 exe 也可以，EDR 加固机器请务必用 cmd）。
3. 程序自动拉起本地双脑（任务栏会出现两个最小化的 llama-server 窗口）：
   速度脑约 10 秒就绪，质量脑约 30–60 秒（Vulkan GPU 加速；无可用 GPU 时自动走 CPU，会变慢）。
4. 界面右上角两个绿点 = 双脑就绪。左栏 = 云端监督脑，右栏 = 本地执行脑。
5. 左栏输入目标（例：`读一下C盘根目录，列出有哪些文件夹。`），云脑派子任务给右栏执行，
   结果只留在右栏面板；左栏只收到「成功/失败」状态位。

系统要求：Windows 10/11 x64；内存 ≥16GB（8B Q4 约占 6GB）；磁盘 ≥7GB；云脑需联网。
首次运行若弹 Windows 防火墙提示 → 允许（服务只绑定 127.0.0.1 回环，不对外）。
若 8080/8081 端口已有同协议服务在跑，程序直接复用，不会重复拉脑。

## 三、双栏与审批模式

- 左栏（云端监督脑 DeepSeek）：只有两个工具 ask_user / dispatch。看不到本地文件、工具输出、细节；不允许写文件。
- 右栏（本地执行脑 Qwen）：shell / 读写文件 / 子Agent / MCP / 智库等全部插件手脚。
- 底部下拉 = 审批模式，默认 **full-auto（零审批，全自动）**：
  | 模式 | 行为 |
  |---|---|
  | full-auto | 工作区内读写、shell 全放行；工作区外写仍拒绝 |
  | auto-edit | 工作区内写放行，其余按白名单 |
  | suggest | 每步弹审批卡（可「常允许」写入白名单） |
  | plan | 只读规划，禁止一切写与执行 |
- 隐私否决（任何模式都生效）：命中 L3 关键词（密码/身份证/银行卡/病历/诊断/余额/工资/验证码/私钥）→ 直接拒绝；工作区外写 → 拒绝；上行永远只有状态位。
- 每步工具调用留痕：`/audit` 查看审计尾。

## 五、自己开发自己（self-dev）

源码完全裸露：`self_list / self_read / self_write` 可读写应用自身任意源码（路径相对 resources/app）。
例：右栏输入 `/self-dev 给智库加一个导出命令`，或左栏派 dispatch 让云脑写插件代码、本地落盘。
插件契约：`plugins/<名>/plugin.json`（name/version/description/main/scope）+ `index.mjs` 导出 `setup(ctx)`；
ctx 提供 registerTool/registerCommand/registerSkill/registerHook/registerService。
改完敲 `plugin_reload` 热重载，无需重启；`/restart` 重启整个应用。
 scope:'cloud' 的插件才会出现在云脑工具视图里（监督通道插件 core-supervision 即如此）。

## 六、密钥、配置与跨机迁移

- **deepseek.key**：云脑密钥。需自行填入（仓库不含任何密钥）。
  ⚠ 该文件是私密凭证：**不要公开分享/上传**；给他人前删除或替换此文件。
  优先级：环境变量 DEEPSEEK_API_KEY > 本文件 > ~/.dsh/.credentials.yaml。
- **brains.json**：换模型/改端口/改 GPU 层数。想升级 35B 满血脑：把
  Qwen3.6-35B-A3B-UD-Q4_K_M.gguf（21GB）与 mtp-A3B-Q4_0.gguf 拷进 brains/，
  质量脑 args 改 `-m Qwen3.6-35B-A3B-UD-Q4_K_M.gguf -md mtp-A3B-Q4_0.gguf`（需 ≥32GB 内存；
  Intel 核显/Arc 可换用 llama-sycl 版后端）。Vulkan 版通吃 Intel/AMD/NVIDIA，无 GPU 自动 CPU。
- **workspace/**：默认工作区。`/ws add <名> <路径>` 增加工作区，白名单按工作区独立。
- **resources/app/data/**：会话 rollout、config、审计。想「新机全新开始」就删掉 data/ 与 whitelist.json。
- 迁移 = 复制整个文件夹（或 zip 解压）。无注册表、无安装器、无外部依赖；U 盘/内网/网盘皆可。

## 七、常见问题

- **双击 exe 无反应/闪退（exit 3）**：企业 EDR/沙箱加固机器（如装了 Sangfor aTrust、Codex 沙箱加固 ACL）
  会拒写 Chromium 沙箱子进程缓存，导致静默退出。用 `启动 Living Steward.cmd`（带 --no-sandbox）即解。
  便携版因此关闭 Chromium 沙箱：渲染进程只加载本地界面、contextIsolation 开启，不载入任何远程网页，风险可控。
- **右上红点**：脑还在加载（等 1 分钟）或启动失败。看任务栏最小化 llama-server 窗口的报错；
  常见为内存不足（换小模型或关占用程序）/ 端口被占（改 brains.json 端口需同步改 core/kernel.mjs 客户端端口）。
- **左栏报错/无回复**：云脑需联网 + 有效 deepseek.key；公司代理环境设环境变量 HTTPS_PROXY。
- **关脑**：关闭任务栏两个最小化 llama-server 窗口；再启动应用会自动重拉。
- **杀毒/EDR 锁文件**：个别企业 EDR 会锁被强杀进程的文件；重启资源管理器或 reboot 后即可删除旧目录。
- **想换更大模型**：关掉便携版拉起的脑窗口，按第六节把新模型及配套文件放进 `brains/`、改好 `brains.json` 后重启。
- ** APK 手机版**：另有 LivingSteward.apk（旧版移动端），与本便携版独立。
